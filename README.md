### Project M / Riivolution mods

The simplest way to play Project M (and other Brawl, Mario Kart Wii... mods) is the built-in
Riivolution support, with no homebrew loader: copy the mod's `riivolution/*.xml` and its files
into `/data/DolphinPS4/User/Load/Riivolution/` (the XML stays in the `riivolution` subfolder, the mod's
own folder next to it), then Triangle on the game -> **Riivolution Patches** -> pick the options, and
start the game.
